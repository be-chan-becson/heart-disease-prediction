# Heart Disease Prediction

Machine learning project to predict heart disease using clinical data.

## Model
Logistic Regression

-Accuracy: ~88.3%

-ROC-AUC: 0.947

-Precision: 0.84

-Recall: 0.88  

-F1-score: 0.86


## Workflow
- Data Cleaning
- Exploratory Data Analysis
- Correlation Heatmap
- Logistic Regression Model
- Confusion Matrix
- ROC Curve

## Dataset
UCI Heart Disease Dataset
